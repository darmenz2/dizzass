# BM1368: повторное использование фильтра RX, VNish 1.3.5

Метод `cgminer 0xe3bc4` / `hwscan 0xf3610`, слот конструктора `+0x90`,
уже представлен в stage6 как `rx-filter-constant-4` и существующей функцией
`vn135_work_rx_filtered_register(4)`, возвращающей `0x40`. Новый C-код не нужен.
Этот пакет добавляет статическую связь конструктора, второго оригинала и
двух достигнутых участков RX с уже восстановленной семантикой.

Dispatcher `0xd2a84` получает сырой selector через `0xfdfbc`. Для значения
`4` он выбирает ветвь, вызывающую `0xe3bc4`, и возвращает `0x40`. В RX вызовы
`0xc4798` и `0xc4a3c` сравнивают этот результат с байтом адреса регистра.
Равенство пропускает общий нижний вызов `0x108938`. Следовательно, `0x40`
здесь обозначает фильтруемый адрес регистра. Отдельный метод `+0x8c` возвращает
ключ `0x44`; число физических ядер этим фильтром не установлено.

[STATIC_CONTRACT.md](STATIC_CONTRACT.md) описывает точные границы, аргументы
доказательства и ограничения. [REUSE.json](REUSE.json) фиксирует существующие
источники и historical receipt, которые переиспользуются без правок.
`evidence/` содержит ограниченные оригинальные байты и reviewed annotations.
Production sources, публичные заголовки, ядро cgminer и `Makefile.am` не меняются.

Из этого каталога на Linux:

```sh
make evidence
python3 -B verify_evidence.py --hwscan /path/to/exact/original/hwscan
python3 -O -B verify_evidence.py --hwscan /path/to/exact/original/hwscan
```

Фактически выполненные статические проверки записаны в
[validation.json](validation.json). Исторические differential tests stage6
исполняют исходные инструкции; в этой работе они не запускаются, и их старые
результаты не считаются новыми проверками. Изменений host-алгоритма нет, поэтому
этот пакет не заявляет новую компиляцию C, GCC/Clang, ASan/UBSan или ARM.

Новые окна RX подтверждают ограниченную связь вызова, сравнения и ветвления
при уже достигнутых register paths. Они не устанавливают всю цепочку извлечения
входных полей, выбора пути и его предусловий, весь RX-поток, тело нижнего вызова,
runtime queue или завершение обработчиков. Соответствие selector `4`
коммерческой модели T21 и аппаратная работоспособность остаются
неподтверждёнными. Оригинальные ELF использованы
только как данные; новые проверки не исполняют и не интерпретируют инструкции.
