# Stage 3: PLL и слой отправки AML

**Готов новый модульный этап, не прошивка для установки.**

Основные изменения находятся на наблюдаемых путях VNish:
`libbitmain/src/pll.c`, `libbitmain/src/aml/chip.c`,
`libbitmain/src/chip/chip1398.c`. Новые заголовки, тесты и инструменты отделены
от исходных путей производителя. Оригинальный cgminer ELF сохранён побайтно.

## Добавлено

- Два алгоритма поиска делителей PLL из 0xff288 и 0xff660: циклы, ограничения,
  округление, выбор кандидата, ранний выход и неуспешный результат. Восстановлен
  32-байтовый формат результата и 56-байтовая структура ограничений.
- Настоящее формирование слова регистра PLL 0x08 по четырём делителям, без
  условной формулы `MHz * 1000`.
- Отправка AML из 0x117f7c: префикс 55 AA, выделение памяти, сериализация, одна
  запись, освобождение ресурсов. Внешние операции передаются через callbacks.
- Маска цепи из 0x118180 с явным входным значением типа чипа.
- Побайтно подтверждённая запись ограничений PLL по адресу 0x5ebea8.
  Она относится к исследованному chip1398-модулю, не является рекомендацией
  частот и не подтверждает выбор этого чипа моделью T21.

Новые случаи дополнительно повторены на сборке Clang; это повтор, не ещё 3 219
уникальных тестов. Отдельно прошли 1 318 синтетических проверок расширенного
локального A32/VFP-интерпретатора. Host C-тесты и ASan/UBSan прошли. Сборка с
fast-math намеренно запрещена; цель full-runtime намеренно не выдаёт майнер.

Результат сборки — host и ARMv7 библиотеки из четырёх C-модулей. Это не ARM
исполняемый cgminer. Из 45 найденных исходных путей частично восстановлены 3;
42 остаются явно невосстановленными и исключены из сборки.

## Что это НЕ подтверждает

Интерпретатор локальный и ограниченный, не независимо сертифицированный.
Внешние вызовы памяти, UART, синхронизации и определения модели при сравнении
явно подменяются; реальная периферия, многопоточность и тайминги не проверены.
Нет подтверждения полного аппаратного тракта, майнинга, автотюна, безопасности
параметров на конкретной плате или полноценной замены VNish.

Upstream cgminer целиком не скачан из-за ошибки DNS в рабочей среде и в архив
не включён. Сборщик наложения сохранён и обновлён, проверяется на локальном
тестовом Git-дереве; полная сборка настоящего upstream пока не проверена.

## Использование

```sh
make -f Makefile.recovery clean all test arm evidence-check sanitize
python3 tests/test_assembler.py
```

Для наложения на зафиксированный публичный cgminer:

```sh
python3 tools/assemble_on_cgminer.py --fetch --output ../cgminer-vnish135
```

Нужен доступ к GitHub или уже имеющийся чистый checkout (параметр `--source`).
Существующая папка исходников и прошивка на ASIC не меняются.

Для продолжения остаются: привязка модели к драйверу, диспетчер транспорта,
инициализация AML/цепей и ответы устройств, полный PLL-контроль, PSU/датчики/
защиты, тракт заданий и nonce, затем состояния автотюна.

**Не устанавливать библиотеку вместо штатного `/usr/bin/cgminer`.**
