# dizzass

Рабочий репозиторий модульной реконструкции VNishNet T21 AML 1.3.5 поверх публичного cgminer.

## База

- Публичная основа: `ckolivas/cgminer`.
- Зафиксированный commit: `b8491c66e7e22f23a9edf095dd1337ee581e88bd`.
- Эта основа содержит публичные Bitmain/S9-изменения; её статус точного предка VNish 1.3.5 **не доказан**.
- Текущая реконструкция: **Stage 14**.
- SHA-256 исходного архива Stage 14: `0c61e8acea79e1e6bad4b1058d50cbb60cf985fcf98ad3f9eb026d4b25178f50`.

## Состояние переноса

Репозиторий инициализирован для переноса. Наличие этого README не означает, что upstream, весь Stage 14 или результаты проверки уже загружены. Завершение импорта будет зафиксировано отдельным коммитом и отчётом.

## Правила работы

Сохранять модульную структуру `src/`, `libbitmain/`, `include/`, `reconstruction/`, `tests/` и `tools/`. Не заменять проект монолитом или успешными заглушками. Сохранять лицензии, авторство и историю публичной базы. Различать восстановленное поведение, новые адаптеры и неподтверждённые гипотезы.

Никакие изменения этого репозитория сами по себе не разрешают установку на ASIC, обновление серверов, смену пулов, напряжений, частот или защит. Текущий результат не является готовым T21-майнером.
