Приватный рабочий репозиторий реконструкции VNishNet T21 AML 1.3.5 поверх настоящего cgminer.

В `main` импортирован `ckolivas/cgminer` на commit:

```
b8491c66e7e22f23a9edf095dd1337ee581e88bd
```

Сохранены **8 051 исходный коммит**, оригинальные файлы, лицензии и авторство. Чистая база также находится в ветке `upstream/ckolivas`. Результат импорта — `UPSTREAM_IMPORT.json`; запуск `Import pinned cgminer history` завершился успешно.

Это копия с сохранённой Git-историей, а не GitHub-fork с изменённым владельцем исходного проекта. Приватность репозитория не менялась. Выбранная публичная база не объявляется доказанным точным предком VNish 1.3.5.

## Перенос Stage 14

**Наличие `migration/STAGE14_IMPORT.json` — признак выполненного импорта архива.** Пока такого файла нет, здесь находятся публичная база и инструменты переноса, но не полный Stage 14.

Для завершения загрузить в корень `main` один неизменённый файл:

```
VNish135_modular_cgminer_stage14.zip
```

Допустим также путь `imports/VNish135_modular_cgminer_stage14.zip`. Ожидаемый SHA-256:

```
0c61e8acea79e1e6bad4b1058d50cbb60cf985fcf98ad3f9eb026d4b25178f50
```

Workflow `Import verified Stage 14 archive` реагирует на этот файл: проверяет архив, внутренний инвентарь и исходный ELF, раскладывает **все 790 файлов**, подключает восстановленные модули через `Makefile.am` и фиксирует результат отдельным коммитом. Другая версия архива, изменённый upstream или конфликт с существующими файлами останавливают импорт. Установок на ASIC нет. Ветка `work/reconstruction` создаётся после импорта, только если её ещё нет.

Сам импортёр проверен локально на точном архиве: совпадение всех 790 файлов, повторный импорт, отказы на конфликтах и symlink. В локальном интеграционном тесте использовалась фикстура Makefile; это не заявление о выполненном GitHub-импорте Stage 14 или полной сборке upstream.

Ручное локальное выполнение импортёра, без commit/push:

```bash
python3 migration/import_stage14.py /path/to/VNish135_modular_cgminer_stage14.zip
```

## После переноса

```bash
make -f Makefile.recovery all arm
make -f Makefile.recovery stage14
```

Сохранять структуру `src/`, `libbitmain/`, `include/`, `reconstruction/`, `tests/`, `tools/` и доказательства. Не объединять всё в один файл и не заменять неизвестную логику успешными заглушками. Правила дальнейшей работы — в `AGENTS.md`.

Оригинальный `overlay-files.json` описывает отдельный Stage 14, не весь объединённый репозиторий. Его старый whole-tree checker требует отдельной адаптации для combined-tree CI; не переписывать контрольные суммы только ради зелёного теста.

**Это проект восстановления, не готовый исполняемый майнер. Не заменять штатный `/usr/bin/cgminer`.** Полная сборка T21, аппаратный запуск, защиты и автотюн не подтверждены самим переносом файлов.
