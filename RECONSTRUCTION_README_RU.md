Текущий public pin ckolivas/cgminer сохранён: найденная публичная S9-линия уже
включена в него. Точная ветка/commit VNish пока не установлены. Удалённый fork
не создан. Новый `tools/prepare_cgminer_fork.py` по умолчанию только показывает план;
`--execute` создаёт public fork и локальную ветку с историей через настроенный gh.
Overlay — только локально, никакой автоматической публикации vendor evidence.

Остались runtime/владение заданиями, T21 dispatch, CRC, запуск хешплат, PSU,
датчики, охлаждение, защиты и автотюн. Полная совместная сборка настоящего upstream
не проведена. **Выход — host/ARMv7 библиотеки, не заменяющий cgminer executable.**
Штатный `/usr/bin/cgminer` не заменять. Исторические материалы Stage 2–13 сохранены.
